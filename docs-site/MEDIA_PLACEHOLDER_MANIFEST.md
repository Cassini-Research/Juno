# Media Manifest

Public docs use real product screenshots and generated architecture diagrams. Video is not required for launch docs.

## Screenshot rules

- Use real Juno app screenshots only.
- Use sanitized sample data only.
- Prefer assets under `public/images/screenshots/live/real/`.
- Do not show private history, customer names, personal email, passwords, repo secrets, financial data, health data, or unrelated desktop windows.
- If a page needs motion to be clear, keep the written instructions complete. Track optional recordings in `VIDEO_NOTES.md`.
