# Privacy and Data Overview

Juno runs speech recognition, writing, and storage locally on this Mac.

| | |
| --- | --- |
| **Runs on** | macOS 15+, Apple Silicon (M-series) — local-first by hardware design |
| **Network during normal use** | Model file downloads only (one-time, ~3–5 GB). No transcripts, no audio, no telemetry. |
| **Account / cost** | None required. Free during the current period; no card, no trial timer, no usage meter. |
| **Used to train models** | Never — there is no opt-in cloud path for user content |

## Key controls

| Control | Default | Why it matters |
| --- | --- | --- |
| Smart Context | On | Helps spelling, style, and selected-text editing. |
| Selected text | On | Lets Juno transform highlighted text. |
| Current app / field | On | Helps Juno understand local writing context. |
| App / window title | On | Helps app-aware writing behavior. |
| Recent clipboard | Off | Separate opt-in context source. |
| Correction learning | On | Learns observed corrections when allowed. |
| History | 90 days | Keeps local transcripts for recovery and review. |
| Recordings | 30 days | Keeps local audio for replay and troubleshooting. |

## Audio and transcripts are never used for training

Juno does not use your audio recordings, transcripts, corrections, or any dictation content to train AI models. All speech processing runs locally on your Mac. Nothing you dictate is sent to a server for model improvement, feedback collection, or any other training purpose.

## Clipboard context vs. pasteboard insertion

Clipboard context and paste-style insertion are different. Juno can use the pasteboard as an insertion mechanism without using your recent clipboard as context. Recent clipboard context is a separate setting and is off by default.

## Secure fields force everything off

Secure / password fields force context, learning, history, audio save, and paste off. There is no setting that disables this.
