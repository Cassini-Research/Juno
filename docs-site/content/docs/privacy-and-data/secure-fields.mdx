# Secure Fields

Secure/password fields are blocked surfaces. When Juno detects a secure field, it forces context, clipboard context, correction learning, transcript history, audio save, and paste off. This protects against accidental capture and accidental insertion.

## What is blocked

| Behavior | Secure field behavior |
| --- | --- |
| Context | Forced off. |
| Clipboard context | Forced off. |
| Learning | Forced off. |
| Transcript history | Forced off. |
| Recording retention | Forced off. |
| Direct paste | Blocked. |

## What to do instead

Move to a normal text field or use Copy Ready in a safe app, then manually decide whether to paste. Do not try to bypass secure-field behavior for credentials, tokens, payment details, or private keys.
