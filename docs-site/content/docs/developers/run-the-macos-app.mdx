# Run the macOS App

The macOS shell is the production user surface. In development, it can be built and tested from the source tree, but user-facing docs should describe the installed app rather than repo scripts.

## Build the shell

Use the maintained shell build script from the repo root:

```bash
./scripts/build_mac_shell.sh
```

For package-style smoke testing, use:

```bash
./scripts/package_juno_macos_app.sh --sign -
```

The ad-hoc signing mode is suitable for local development only. Public distribution requires Developer ID signing, hardened runtime, notarization, and stapling.

## Launch path

The shell should start or connect to the local voice engine, verify compatibility, show setup status, request permissions, capture audio locally, and use copy-ready fallback when insertion is unavailable.

## Manual GUI checks

Run native GUI checks on a real Mac:

- First launch and onboarding.
- Microphone permission.
- Accessibility permission.
- Fn / Globe shortcut start and stop.
- HUD state behavior: checking microphone, waiting for speech, listening, polishing, inserted, copy ready, error.
- Successful insertion into a normal text field.
- Copy-ready fallback in unsupported or unsafe surfaces.
- Secure/password-field suppression.
- History entry creation and linked recording replay.
