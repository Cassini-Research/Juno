# Package the App

Juno ships as a native `Juno.app` with a managed local engine payload.

## Local package command

For local package testing from the current source tree:

```bash
./scripts/package_juno_macos_app.sh --sign -
```

The `--sign -` path is ad-hoc signing for local development. Do not use it as the external distribution path.

## Production bundle shape

A production bundle should contain:

- `Juno.app/Contents/MacOS/Juno` for the native Swift app.
- A signed engine launcher/helper that starts the local engine without assuming a repo checkout.
- `Juno.app/Contents/Resources/engine/` for the pinned engine payload or standalone runtime artifact.
- Helper binaries for paste, hotkey, text monitoring, capability checks, and hosting.
- Clear Application Support and Logs paths for models, settings, history, retained audio, local token, endpoint metadata, and diagnostics.

## Compatibility requirement

The packaged app should verify engine compatibility before dictation or settings calls. Protocol mismatch, stale services, or wrong runtime role should show a repairable product state rather than silently attaching to the wrong process.

## Package smoke

After packaging:

```bash
./scripts/smoke_juno_macos_app.sh
```

Then perform manual clean-install GUI QA on a real Mac.
