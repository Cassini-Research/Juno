# Signing and Notarization

External macOS distribution requires Developer ID signing, hardened runtime, notarization, and stapling.

## Release signing requirements

A public Juno build must satisfy:

- App and helper binaries signed with Developer ID Application.
- Hardened runtime enabled with the minimum required entitlements.
- Notarization submitted and accepted by Apple.
- Notarization ticket stapled to the distributed app or DMG.
- Gatekeeper assessment passes on a clean Mac.

## Commands to verify release output

After release signing and notarization, assess the built app:

```bash
spctl --assess --type execute --verbose dist/Juno.app
```

Inspect code signatures:

```bash
codesign --verify --deep --strict --verbose=2 dist/Juno.app
```

## Helper binaries

Every helper included in the bundle must be signed as part of the release. Helper identity, entitlements, and hardened runtime behavior should be checked alongside the main app, not after the fact.

## Policy

Never publish a public download that only works because Gatekeeper is bypassed. Gatekeeper success is a release gate, not a support workaround.
