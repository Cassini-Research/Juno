# Local Setup

This page is for source contributors. Normal users should install the packaged Juno app and should not need a repo checkout, virtual environment, or Terminal workflow.

## Bootstrap the Python runtime

From the repo root:

```bash
./scripts/bootstrap_v2.sh
source .venv/bin/activate
```

For the full local development environment:

```bash
./scripts/bootstrap_full_v2.sh
```

## Check the environment

Run the local doctor before live testing:

```bash
./scripts/doctor_v2.sh
```

Then run the maintained test suite:

```bash
./scripts/run_tests_v2.sh
```

## macOS prerequisites

For native app testing, use a real macOS machine. Enable Microphone and Accessibility for the app or development binary being tested. Insertion, secure-field avoidance, app switching, and global shortcut behavior require GUI QA; they cannot be fully proven by headless tests.

## Development data paths

Production data resolves under the Juno Application Support area. Development flows may write under `.juno_v2_demo/`, `.juno_v2_runtime/`, `.juno_v2_logs/`, or `.juno_v2_memory/`. Do not use development paths in user-facing product copy.
