# License

The repository license file controls how Juno code can be used, copied, modified, and redistributed. Keep this page synchronized with the root license file and any third-party notices included in the app bundle.

## Before contributing

By contributing, you should be comfortable that your contribution can be distributed under the repository’s public license. Do not submit code, models, assets, icons, datasets, or copied snippets unless you have the right to contribute them.

## Third-party components

Juno uses model, runtime, packaging, and macOS components that may have their own licenses. Release packaging should include required notices for dependencies, bundled models, helper binaries, and any vendored assets.

## Release requirement

Do not publish the public repository or public app bundle without:

- A root `LICENSE` file.
- Dependency and model notices where required.
- A clear policy for external contributions.
- Review of bundled assets, icons, fonts, and media rights.
