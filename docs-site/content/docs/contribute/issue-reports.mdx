# Issue Reports

A useful issue report identifies the affected layer and the steps to reproduce it.

## Include

- macOS version and device model.
- Juno version or commit.
- Whether Microphone and Accessibility permissions are granted.
- The target app and field type.
- The exact HUD state shown.
- Whether text was inserted, copy-ready, or lost.
- Whether history and replay were created.
- Steps to reproduce.
- Screenshots or screen recordings using non-private sample text.
- Support bundle when requested.

## Do not include

Do not paste private dictation content, passwords, tokens, personal messages, private screenshots, retained audio, or raw support archives into public issues. Redact before sharing.

## Good title format

Use a title like:

```text
[Insertion] Copy Ready appears in Slack compose even though Accessibility is enabled
```

or:

```text
[Microphone] HUD stays on Checking microphone after clean install on macOS 15
```
