# Code of Conduct

Juno’s community standard is simple: be precise, respectful, and useful. The project deals with voice, writing, local data, and privacy-sensitive behavior, so contributors should treat user trust as part of the engineering surface.

## Expected behavior

- Discuss ideas and code directly without personal attacks.
- Keep bug reports factual and reproducible.
- Respect privacy when sharing screenshots, logs, audio, or support bundles.
- Do not pressure users to share private dictation content.
- Credit others’ work accurately.
- Keep debates focused on product behavior, engineering tradeoffs, and evidence.

## Unacceptable behavior

Harassment, threats, doxxing, targeted abuse, spam, repeated bad-faith disruption, and publication of private user data are not acceptable.

## Enforcement

Maintainers may moderate issues, pull requests, discussions, or community spaces to protect users and contributors. Severe privacy or security violations may lead to immediate removal from project spaces.
