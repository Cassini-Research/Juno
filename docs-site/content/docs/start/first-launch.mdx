# First Launch

Setup happens in the app. No Terminal commands are required.

## System requirements

| Requirement | Detail |
| --- | --- |
| **macOS version** | macOS 15 (Sequoia) or later |
| **Mac model** | Apple Silicon (M1, M2, M3, M4, …) — Intel Macs are out of scope |
| **Disk space** | ~3–5 GB for the local speech and writing models (one-time download) |
| **Microphone** | Built-in or external; works with AirPods, USB mics, or audio interfaces |
| **Account** | None — Juno does not require sign-in, an Apple ID, or a card |
| **Cost** | Free during the current period; no trial timer, no usage meter |

## Permission detail

| Permission | Required | Effect if missing |
| --- | --- | --- |
| Microphone | Yes | Dictation cannot start — Juno never receives audio frames. |
| Accessibility | Yes (for direct insertion) | Juno still transcribes, but every session ends in Copy Ready instead of inserting into the field. |
| Speech Recognition | No | Live captions are unavailable. Final dictation still works. |
| Reminders, Calendar, Notes (Voice Actions) | No | "Hey Juno" actions cannot create items. Dictation and Voice Commands still work. |

You can revisit any of these later in **Settings → Permissions**, or by re-running onboarding from the menu bar.

## If a step blocks

- **Stuck on Setup** — the engine is still warming or a model is still downloading. Leave Juno open for a few minutes. If it never reaches Ready, see [Voice Engine Not Connected](/docs/troubleshooting/voice-engine-not-connected).
- **Stuck on Actions** — pick a default (Off is fine). The step is gated on you making a decision, not on enabling anything.
- **Try it shows Copy Ready instead of inserting** — Accessibility was not applied. Quit Juno, confirm Accessibility in System Settings, reopen Juno.

## After first launch

Open any writing app, such as Notes, Mail, or Messages, and run the [Quickstart](/docs/start/quickstart).
