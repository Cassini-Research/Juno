# What is Juno?

**Juno is local voice writing for macOS.** Press the shortcut, speak, and Juno inserts final text in the active app.

## Core features

- **Revise by voice** — delete recent text, shorten a sentence, convert text into bullets, or rewrite a selection.
- **Create Actions** — route supported phrases to Apple Reminders, Apple Notes, and Calendar-backed alarms.
- **Use app-specific writing styles** — set different defaults for Mail, Slack, Notes, Cursor, and other writing surfaces.
- **Add local vocabulary and snippets** — teach Juno names, terms, replacements, snippets, and corrections stored on this Mac.

| | |
| --- | --- |
| **Runs on** | macOS 15+, Apple Silicon (M-series) |
| **Cost** | Free during the current period; no account, card, trial timer, or usage meter |
| **Where audio goes** | This Mac. Not a cloud service. Not used for training. |

## Live preview and finalized text

Juno separates live captioning from final inserted text.

**While you speak —** the HUD's live caption shows what Juno is hearing right now:

> *"umm wait no, ask Avery to review the install flow before Friday"*

The live caption shows interim recognition and can include false starts, filler, or partial phrases.

**When you finish —** Juno reconciles the final transcript, applies the active writing style, and inserts finalized text:

> *"Avery, could you review the install flow before Friday?"*

The live caption confirms that audio is being recognized. The finalized text is the result Juno inserts or holds as Copy Ready.

## Per-app writing

Pin a writing style per app so Juno can apply the right output format automatically.

> Spoken: *"ask Avery to review the Q3 onboarding notes before Friday"*

| App | What lands |
| --- | --- |
| **Mail** (Formal email) | Avery, could you review the Q3 onboarding notes before Friday? I would like to identify any issues before release. |
| **Slack** (Casual chat) | avery can you review q3 onboarding before friday? |
| **Apple Notes** (Structured notes) | **Q3 onboarding** — Avery review before Friday. |

Per-app writing keeps output format aligned with the target surface, without changing styles manually for each session.

## Revise text by voice

After Juno writes text, use a short command on the recent passage or selected text:

- *"warmer"* — softens the register
- *"shorter"* — compresses to the essentials
- *"bullets"* — restructures as a list
- *"more formal"* — lifts to professional prose
- *"translate that to Spanish"* — translates the passage

Commands can also be combined:

> *"Make that shorter, then turn it into bullets, then translate that to Spanish."*

Juno applies each supported transformation in sequence.

## Voice Actions

Voice Actions parse supported action phrases and create one item per action:

> *"Juno, take a note about my one-on-one with Sarah, and remind me to follow up tomorrow morning."*
> → 1 note (Apple Notes) + 1 reminder (Apple Reminders, tomorrow 8 AM)

> *"Juno, note tomorrow's 7 AM flight — passport renewed, packing list almost done. Remind me at 5 to charge the AirPods, and wake me at 4:30 so I make it."*
> → 1 note + 1 reminder (5 PM) + 1 alarm (4:30 AM, Calendar-backed so it rings even with Juno closed)

> *"Juno, set an alarm for 6:45 tomorrow and remind me to call mom in the evening."*
> → 1 alarm + 1 reminder (today 7 PM, the "evening" default)

The word "Juno" at the start of an utterance is a content cue that routes the sentence as an Action. The shortcut opens the microphone; Juno does not listen passively. See [Actions](/docs/use-juno/actions) for the full grammar.

## Daily loop

1. **Place the caret** in whatever app you were writing in
2. **Press Fn (or your chosen shortcut)** — the HUD opens
3. **Speak naturally** — the live caption shows what Juno is hearing
4. **Pause naturally** — Juno can place finalized partials at each pause; sessions can span multiple pauses
5. **Press Fn again** — the final result lands in the field, replacing the partials with the polished version

Press Esc at any time to cancel; a cancelled session is not inserted later.

## Good first apps to try

- A reply in **Mail** or **Messages**
- Meeting notes in **Apple Notes** or **Obsidian**
- A **Slack** standup update
- A prompt for **ChatGPT**, **Claude**, or **Cursor**
- A draft idea that should become a clean paragraph

After the first successful dictation, configure Voice Actions and Per-app writing.
