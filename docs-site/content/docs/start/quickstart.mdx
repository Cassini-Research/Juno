# Quickstart

Start with Notes or Mail before changing settings.

Choose a standard text field for the first run, such as Notes, Mail compose, Messages, a Slack draft, or a blank document. Avoid password inputs, payment forms, permission prompts, terminals, and remote-desktop windows for the first run.

**Requirements:** macOS 15+ on Apple Silicon, with Microphone and Accessibility permissions granted during [First Launch](/docs/start/first-launch). No account, no card.

## Required permissions

| Permission | Why it is needed | Where to grant |
| --- | --- | --- |
| Microphone | To capture your voice | System Settings → Privacy & Security → Microphone |
| Accessibility | To inspect the focused field and insert text | System Settings → Privacy & Security → Accessibility |
| Speech Recognition (optional) | Live captions inside the HUD | System Settings → Privacy & Security → Speech Recognition |

If you ran first launch, the first two are already on. If you skipped it, see [First Launch](/docs/start/first-launch).

## What "Hey Juno" is for

For your first dictation, just press the shortcut and talk. The **"Hey Juno"** (or shorter **"Juno,"**) prefix is for Voice Actions — saying *"Hey Juno, remind me to call Sarah at 6pm"* creates a Reminder instead of writing the words as text. See [Actions](/docs/use-juno/actions) for the full grammar including compound utterances ("note this, remind me to do that, wake me up at X").

Normal dictation needs no prefix — the shortcut is what opens the microphone.

## If it worked

You'll see the polished sentence in Notes — punctuated, capitalized, no "uh" or "um."

Next:
- Try a longer thought — three or four sentences with natural pauses
- Try `scratch that` mid-sentence to erase the current phrase ([all voice commands](/docs/use-juno/voice-commands))
- Try a writing style — switch to **Formal email** in Styles and dictate the same sentence into Mail ([Styles](/docs/use-juno/styles))

## If the first run fails

| What you saw | Where to go |
| --- | --- |
| HUD never appeared | [Shortcuts and HUD](/docs/start/shortcuts-and-hud) |
| HUD stuck on Checking microphone | [Microphone troubleshooting](/docs/troubleshooting/microphone) |
| HUD reached Listening but no words | [Microphone troubleshooting](/docs/troubleshooting/microphone) — speech-detection section |
| Text appeared in the HUD as Copy Ready instead of the field | [Insertion and Copy Ready](/docs/troubleshooting/insertion-and-copy-ready-output) |
| Words wrong / hallucinated | [Transcription accuracy](/docs/troubleshooting/transcription-accuracy) |
| Home says the engine is not ready | Open Juno → Settings → Models |
