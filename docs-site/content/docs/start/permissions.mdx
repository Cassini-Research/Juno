# Permissions

Juno needs Microphone and Accessibility. Speech Recognition and Input Monitoring are optional.

| Permission | Required? | What it unlocks | Where to grant |
| --- | --- | --- | --- |
| **Microphone** | Yes | Audio capture during a session | System Settings → Privacy & Security → Microphone |
| **Accessibility** | Yes for direct insertion | Field inspection + safe text placement | System Settings → Privacy & Security → Accessibility |
| **Speech Recognition** | No | Apple's on-device live captions in the HUD | System Settings → Privacy & Security → Speech Recognition |
| **Input Monitoring** | Only for some custom shortcuts | Key combinations beyond Fn / Globe (Control+Space, Option+Space) | System Settings → Privacy & Security → Input Monitoring |

Voice Actions needs three Apple-app automation permissions: **Reminders Automation**, **Notes Automation**, and **Calendar Automation**. These are app-specific permissions granted at first use, not macOS-wide ones. See [Actions](/docs/use-juno/actions).

## Microphone

Open **System Settings → Privacy & Security → Microphone** and toggle Juno on. After granting, quit and reopen Juno. The HUD will not move past Checking microphone until the OS actually delivers audio frames to the app.

## Accessibility

Open **System Settings → Privacy & Security → Accessibility** and toggle Juno on. If you have multiple copies of Juno installed (a Beta build alongside a release build, or one in `/Applications` and another in `~/Downloads`), macOS grants Accessibility to the *exact bundle path*, not the app name. Always launch the one in `/Applications/Juno.app` — the one you granted.

Accessibility does not override secure-field blocking. Even with it granted, Juno refuses to insert into password or secure-type inputs.

## Speech Recognition (optional)

This is Apple's on-device recognizer, used only for live captions inside the HUD while you speak. Juno's own dictation runs through its local voice engine — turning Speech Recognition off does not affect the transcript that lands in your app.

## Input Monitoring (only for custom shortcuts)

Fn / Globe does not need Input Monitoring. If you pick Control+Space, Option+Space, or a custom combo and the shortcut does not fire, macOS is asking for Input Monitoring. Grant it for Juno, quit, and reopen.

## Resetting a stuck permission

If macOS shows Juno as granted but Juno still reports the permission as missing:

1. Open **System Settings → Privacy & Security → [the permission]**
2. Toggle Juno **off**, wait 3 seconds, toggle **on**
3. Fully quit Juno from the menu bar (not just close the window) and reopen

If that does not help, see [Permissions Reset](/docs/troubleshooting/permissions-reset).
