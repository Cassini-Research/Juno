# Start Using Juno

Juno works inside the Mac apps where you already write. Press the shortcut, speak, and Juno inserts final text in the active field.

<div className="juno-doc-facts" aria-label="Juno basics">
  <div>
    <span>Runs on</span>
    <strong>macOS 15+</strong>
    <p>Apple Silicon Macs.</p>
  </div>
  <div>
    <span>Shortcut</span>
    <strong>Fn / Globe</strong>
    <p>Start and stop dictation.</p>
  </div>
  <div>
    <span>Account</span>
    <strong>Not required</strong>
    <p>No sign-in or usage meter.</p>
  </div>
</div>

## How it works

<div className="juno-doc-steps">
  <div>
    <span>1</span>
    <strong>Place the cursor</strong>
    <p>Click into Notes, Mail, Slack, Cursor, a browser field, or any supported text surface.</p>
  </div>
  <div>
    <span>2</span>
    <strong>Speak naturally</strong>
    <p>Use full sentences. The HUD can show a live caption while Juno listens.</p>
  </div>
  <div>
    <span>3</span>
    <strong>Insert final text</strong>
    <p>Press the shortcut again. Juno inserts final text or shows Copy Ready when direct insertion is not safe.</p>
  </div>
</div>
