Settings controls dictation, storage, privacy, models, and app behavior.

## Section order

1. **General** — Appearance, Show in Dock, Keep recordings for, Live transcriptions, HUD position.
2. **Dictation** — Shortcut, HUD sounds, Pause sensitivity, Show word count, Home greeting.
3. **Audio input** — Microphone processing toggle.
4. **Writing & language** — Language picker.
5. **Storage** — Keep history for, plus storage cleanup actions.
6. **Privacy & learning** — Smart Context sources, correction learning, clipboard context.
7. **Permissions** — Microphone, Accessibility, Speech Recognition, Input Monitoring deep links.
8. **Models** — Local speech and writing model status, install, repair.
9. **Updates & app** — Launch on Login, software updates, Developer mode.

The **Voice Actions** entry is a pointer card at the top of Settings that links to the [Voice Actions](/docs/use-juno/actions) page in the sidebar.

## What to set first

Three settings affect every dictation. Get these right before you tune anything else.

| Setting | Where | Recommended |
| --- | --- | --- |
| Shortcut | Dictation → Shortcut | Fn / Globe |
| Live transcriptions | General → Live transcriptions | On (you see what's being captured in real time) |
| Pause sensitivity | Dictation → Pause sensitivity | Default; raise it if Juno commits text before you finish thinking |

## General

| Control | What it does |
| --- | --- |
| Appearance | Light, Dark, or System (matches macOS) |
| Show in Dock | Off keeps Juno menu-bar-only |
| Keep recordings for | Forever / 30 days (default) / 7 days / Never |
| Live transcriptions | When on, the HUD shows interim recognition while you speak |
| HUD position | Top, Bottom, or Auto |

## Dictation

| Control | What it does |
| --- | --- |
| Shortcut | The key you press to start and stop a session |
| HUD sounds | Start, finish, and feedback chimes |
| Pause sensitivity | How long a pause must be before Juno commits a polished partial |
| Show word count | Brief confirmation after finalization |
| Home greeting | The first name shown on Home — set during onboarding, change here |

## Audio input

Microphone processing controls (echo cancellation, noise suppression). **Off by default** — turn on if your raw mic signal is noisy. If turning it on causes clipped, hollow, or distorted output, turn it back off.

## Writing & language

Five language options plus a translation toggle:

| Option | What it does |
| --- | --- |
| **Auto-detect** | Juno identifies the language per session |
| **English** | English only |
| **Spanish** | Spanish only |
| **Mandarin Chinese** | Mandarin only |
| **Hindi + English** | Code-switching pair — recognizes both languages in the same sentence |
| **Keep original** *(separate toggle)* | Skip translation — keep what was spoken in its original language |

If you naturally mix two languages, pick the pair mode. Otherwise Auto-detect is the right default.

## Storage

| Control | What it does |
| --- | --- |
| Keep history for | Forever / 90 days (default) / 30 days / 7 days / Never |
| Clear history | One-click wipe of all transcript entries |
| Delete recordings | One-click wipe of all retained audio (transcripts stay) |
| Clean up now | Runs the retention cleanup immediately instead of waiting for the daily pass |

Retention for history and recordings is independent. You can keep transcripts forever and audio for a day, or vice versa.

## Privacy & learning

| Toggle | Default | What it controls |
| --- | --- | --- |
| Smart Context (master) | On | Master switch for context sources below |
| Selected text | On | Anchor for voice-based selected-text edits |
| Current field | On | Continue mid-paragraph, match style already in the field |
| App / window title | On | Calibrate register (Slack vs Pages, etc.) |
| Recent clipboard | Off | Reference your last copy when relevant |
| Correction learning | On | Whether your edits get folded into Dictionary & Memory automatically |

See [Smart Context](/docs/privacy-and-data/smart-context) for how each context source changes output.

## Permissions

Read-only status for Microphone, Accessibility, Speech Recognition, and Input Monitoring. Each row deep-links to the matching System Settings pane.

If a permission shows as missing here but you granted it in System Settings, quit and reopen Juno. macOS does not reflect the change until the app restarts.

## Models

Status panel for the local voice engine and writing models. Three model categories:

- **Fast preview** — the quick partial-recognition model that produces live captions
- **Final dictation** — the higher-quality model that produces the polished result
- **Writing engine** — the on-device writer used by Styles and the rewriting Voice Commands

Each row shows installed / installing / ready / failed. **Repair** re-fetches or re-warms the model. If repair does not resolve a failure, see [Voice Engine Not Connected](/docs/troubleshooting/voice-engine-not-connected).

## Updates & app

| Control | What it does |
| --- | --- |
| Launch at Login | Juno starts when your Mac boots |
| Check for updates | Manual update check |
| Automatic updates | Whether new releases install in the background |
| Developer mode | Exposes engine diagnostics, raw logs, and the bridge inspector — leave off unless instructed |
