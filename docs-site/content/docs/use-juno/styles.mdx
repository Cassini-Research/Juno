# Styles

A style controls how Juno formats final text.

> Spoken: *"ask Avery to review the Q3 onboarding notes before Friday"*

| Active style | What lands |
| --- | --- |
| **Verbatim** | ask Avery to review the Q3 onboarding notes before Friday |
| **Casual chat** | avery, can you review the q3 onboarding notes before friday? |
| **Formal email** | Avery, could you review the Q3 onboarding notes before Friday? I would like to identify any issues before release. |
| **Structured notes** | **Q3 onboarding** — Avery to review before Friday. |
| **Polished rewrite** | (on a selected paragraph) Compresses or expands the selection per your spoken instruction. |
| **Commands** | (on selected text) Treats the spoken sentence as an instruction acting on the selection. |

You can also create custom styles. See [Custom Styles](/docs/use-juno/custom-styles).

## The six built-in styles

| Style | When to use | What it does to your speech |
| --- | --- | --- |
| **Verbatim** | Quotes, code-adjacent prose, legal phrasing, anything where rewriting would be wrong | Keeps your words as close to what you said as possible. Light cleanup of disfluencies only. Voice commands (`scratch that`, `new paragraph`) still work. |
| **Casual chat** | Slack, iMessage, quick replies, team notes | Cleans up speech artifacts while preserving informal tone, contractions, and your phrasing. |
| **Formal email** | Mail compose, professional messages, external communication | Rewrites into structured email prose, adjusts tone, removes filler, and improves readability. |
| **Structured notes** | Meeting notes, action items, anything bullet-shaped | Organizes content into bullets, headings, or a clean outline based on the natural structure of what you said. |
| **Polished rewrite** | Rewriting a highlighted passage | Full rewrite of the selected text. Replace, rephrase, expand, or condense based on what you dictate. Requires selected text. |
| **Commands** | Telling Juno to act on selected content | Interprets your dictation as an instruction rather than text to write. Used for selected-text transformations. |

There is also an implicit **Default** style used when no specific style is selected. It provides balanced light cleanup with minimal tone changes.

## Quick vs heavy: which styles use the writing engine

| Style | Path | Latency |
| --- | --- | --- |
| Verbatim | Speech → light cleanup → insert | Fastest |
| Default | Speech → light cleanup → insert | Fast |
| Casual chat | Speech → light cleanup → insert | Fast |
| Formal email | Speech → writing engine → insert | Slightly slower (engine pass) |
| Structured notes | Speech → writing engine → insert | Slightly slower (engine pass) |
| Polished rewrite | Selected text + speech → writing engine → replace | Engine pass; waits for final result |
| Commands | Speech → command parser → action on selection | Engine pass; waits for final result |

The writing engine runs locally; it adds 1–2 s versus light cleanup.

## How to switch styles

Three places:

- **Style picker in the Juno popover** — for a one-off session, change the style before pressing the shortcut
- **[Per-app writing](/docs/use-juno/per-app-writing)** — pin a different default style per app. Slack uses Casual chat automatically; Mail uses Formal email; Cursor uses Verbatim or a custom code-comment style.
- **[Custom Styles](/docs/use-juno/custom-styles)** — make your own for a specific recurring task (standup, code comment, changelog entry)

## Writing engine requirements

Verbatim, Default, and Casual chat work without loading the writing engine. Formal email, Structured notes, Polished rewrite, and Commands require the writing engine. If the engine is unavailable, those styles fall back to Default behavior and the HUD shows a brief notice.

Check engine status in **Settings → Models → Writing engine**. If it shows failed, click **Repair**. If repair does not resolve the issue, see [Voice Engine Not Connected](/docs/troubleshooting/voice-engine-not-connected).

## Selected text and the rewrite styles

Polished rewrite and Commands both need a selection. Select the text in your app first, then start a Juno session — the active selection becomes the target.

When a session starts with selected text, Juno waits for the final result before replacing the selection. Partial commits do not overwrite highlighted text during the rewrite.
