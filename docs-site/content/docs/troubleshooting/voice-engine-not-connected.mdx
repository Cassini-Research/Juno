# Voice Engine Not Connected

If the engine is unavailable, Home shows Offline and Settings shows Install or Repair.

## Common causes

- **Models still preparing** — Setup step downloaded but has not warmed yet. Wait, then check Settings → Models.
- **Stale engine process** — A previous Juno session left a hanging engine process. Quit Juno completely from the menu bar and reopen.
- **Model file corrupted** — Disk-level damage during a download. Settings → Models → Repair re-fetches.
- **Engine and shell version mismatch** — Happens during a partial update. A full quit + reopen usually picks up the matched pair.

## When to collect a support bundle

If Models reports ready but dictation still cannot reach the engine, create a support bundle and include the exact HUD message, the app version, and whether this happened after an update.
