# History and Recordings

History and recordings have separate retention controls.

## Missing history

Check whether history retention is disabled globally or for the app you used. Secure/password fields force history off, so no entry should be retained from those surfaces. Also confirm the session was not cancelled before finalization.

## Missing replay

Replay is only available while the linked recording exists. If recording retention is off, the recording expired, or cleanup removed it, the history entry may remain without replay.

## Unexpected recordings

Open Settings → Storage and set **Keep recordings for** to a shorter duration or Off. Use **Delete recordings…** to remove retained audio. Use Per-app writing if a whole app should never retain recordings.

## Cleanup

Use **Clean up now** to apply retention immediately. Use **Clear history…** when you want transcript history removed too.
