## Multiple app copies

If you have multiple Juno builds, macOS can grant Accessibility to one copy while you run another. Delete old builds or rename them clearly, then grant permission to the exact app you are using.

## Secure fields still block

Even with Accessibility permission, secure/password fields remain blocked. Context, learning, history, audio save, and paste should stay off in those fields.
