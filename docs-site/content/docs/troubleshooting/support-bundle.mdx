# Support Bundle

A support bundle captures app state, logs, and HUD transitions without transcripts or audio.

## How to generate one

1. Open **Juno → Settings → Advanced → Logs**
2. Click **Generate support bundle…**
3. Finder opens with the bundle file (a `.zip`) revealed
4. Attach it to your support email or GitHub issue

The bundle saves under `~/Library/Logs/Juno/`. If the generate button fails, the status line tells you why (usually a permission issue on the logs directory).

## What's inside

| Section | Why it is included |
| --- | --- |
| App version + build channel | So we can match against a known release |
| macOS version + hardware | Compatibility context |
| Shell log (recent) | Swift-side errors, permission flips, HUD transitions |
| Engine log (recent) | Python-side errors, model load status, transcription pipeline |
| Recent HUD state transitions | The exact state sequence around the failure |
| Permission status snapshot | Microphone / Accessibility / Speech Recognition / Automation grant state |
| Engine readiness snapshot | Which models are installed / installing / ready / failed |
| Session metadata (last few sessions) | App name, duration, success/Copy Ready/Blocked — **no transcript content, no audio** |

## What's *not* inside

- Your transcripts
- Your audio recordings
- Your Dictionary & Memory entries
- Anything you have dictated

The bundle is metadata + logs only. Open the `.zip` and inspect before sharing if you want to confirm — everything is plain text.

## When to include context yourself

Even with the bundle, a one-sentence description of what you were doing speeds diagnosis enormously:

| Useful context | Example |
| --- | --- |
| What you were trying to do | *"Dictating a reply in Mail, used Fn / Globe."* |
| Which HUD state stalled | *"Stuck on Refining for 8 seconds."* |
| Whether the clean Notes test works | *"Notes works; Slack always shows Copy Ready."* |
| When it started | *"After macOS 15.4 update."* |

## What to redact before sharing

If you attach a screenshot of the HUD or a window:

- Blur any window titles that include client names or project codes
- Blur any visible text in the destination app
- Don't include screenshots of your password manager, banking apps, or anything in a secure field

## Related diagnostics

The same Settings → Advanced area has:

- **Show logs in Finder** — opens the log directory without bundling
- **Refresh permissions** (under Diagnostics) — re-checks macOS permission state without restarting
- **Export diagnostics…** (under Diagnostics) — downloads a broader engine state export

Use **Generate support bundle…** for support requests. Use the other exports when debugging locally and raw data is required.
