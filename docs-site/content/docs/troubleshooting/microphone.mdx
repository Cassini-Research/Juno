## If audio is distorted

Open Settings → Audio and test **Mic processing** both off and on. It is off by default because system voice-processing paths can behave differently across Macs and macOS versions. If turning it on causes silence, distortion, or repeated nonsense output, turn it off and test again.

## If Juno hears silence

Move closer to the microphone, lower background noise, or check that the correct input device is selected in **System Settings → Sound → Input**. On laptops, the built-in mic catches room reflections — using a headset or external mic is the single biggest accuracy win.
