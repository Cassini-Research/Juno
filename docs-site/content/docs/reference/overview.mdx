## The everyday loop, in shortest form

1. Click into a text field
2. Press **Fn** (or your chosen shortcut)
3. Speak — wait for the HUD to show Listening
4. Pause naturally; polished text lands on each pause
5. Press **Fn** again to finalize

Full version: [Speak and Insert](/docs/use-juno/speak-and-insert).

## Hard rules (not configurable)

Enforced regardless of any user setting:

- Secure / password fields → capture, context, history, recordings, learning, paste all forced off
- Audio, transcripts, and corrections → never used to train any model
- Network activity → model file downloads only; no telemetry, no usage data, no account check-in
- Cancelled sessions → never produce a late paste
