# History and Recordings

Reference for History and retained audio.

## What a History entry contains

| Field | Notes |
| --- | --- |
| Final transcript | The text that was inserted or held as Copy Ready |
| App | Which app was focused during the session |
| Time | When the dictation happened |
| Insertion result | Inserted / Copy Ready / Blocked |
| Replay | Available when a linked recording still exists |
| Action outcomes | If Voice Actions ran (note saved, reminder created), the result appears here |

Secure-field sessions are never recorded, so they do not appear in History.

## Per-entry actions

| Action | Effect |
| --- | --- |
| **Copy** | Copies the final transcript to the clipboard |
| **Replay** | Plays the linked recording through your Mac's output |
| **Reprocess** | Runs the retained audio through the current processing path again — useful for applying a different style to a past session |
| **Save phrase** | Adds the transcription to your vocabulary or snippets |
| **Delete** | Removes the entry and the linked recording (if one exists) |

Replay and Reprocess both need a retained recording. If recording retention expired, the row shows the transcript but the playback control is disabled.

## Bulk actions (Settings → Storage)

| Action | Effect |
| --- | --- |
| **Clear history** | Wipes every transcript and every linked recording. Irreversible. |
| **Delete recordings** | Wipes all audio; transcripts stay. |
| **Clean up now** | Runs the daily retention cleanup immediately. |

## Retention

| Data | Default | Available windows |
| --- | --- | --- |
| Transcript history | 90 days | 7 / 30 / 90 / Forever / Never |
| Recordings | 30 days | 7 / 30 / Forever / Never |

History and recordings are independent. A transcript can outlive its audio (replay disappears, transcript stays). Audio can be off entirely while transcripts are kept forever.

## Empty / error states

| State | Meaning |
| --- | --- |
| **No history yet** | You have not completed a successful dictation, or History is disabled globally |
| **No history for this app** | Per-app history is disabled (Per-app writing → that app) |
| **Voice engine offline** | History loads once the engine reconnects |
| **Could not load history** | Read failure on the local database — see [History and Recordings troubleshooting](/docs/troubleshooting/history-and-recordings) |

## Storage location

`~/Library/Application Support/com.juno.shell/Workbench/history.sqlite` for transcripts; `~/Library/Application Support/com.juno.shell/Workbench/recordings/` for audio files. Don't edit these directly — use the in-app controls.
