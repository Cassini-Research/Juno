# Privacy Reference

A matrix of local storage, context, and secure-field behavior.

## Stored locally

There is no cloud component. All of these live on this Mac:

- Audio frames during a session
- Transcripts in History (default 90 days)
- Retained recordings (default 30 days)
- Dictionary, snippets, replacements, style entries
- Corrections used for personalization
- Settings, including per-app overrides

Network activity in normal operation: model file downloads only. No usage pings, no telemetry, no account check-in.

## Retention rules

| Data | Default | Range |
| --- | --- | --- |
| Transcript history | 90 days | 7 / 30 / 90 / Forever / Never |
| Recordings | 30 days | 7 / 30 / Forever / Never |

History and recordings are independent — different retentions for each are allowed. See [History and Recording Retention](/docs/privacy-and-data/history-and-recording-retention).

## Smart Context sources

Five sources. Each controlled individually in Settings → Privacy & learning, or per-app in Per-app writing.

| Source | Default | What it does |
| --- | --- | --- |
| Selected text | On | Anchor for voice-based selected-text edits |
| Current field | On | Continue your sentence mid-paragraph, match style |
| App / window title | On | Calibrate register (Slack vs Pages, etc.) |
| Dictionary & Memory | On where allowed | Apply your vocabulary, replacements, snippets, style entries |
| Recent clipboard | Off | Reference your last copy when relevant |

Detail at [Smart Context](/docs/privacy-and-data/smart-context).

## Secure fields — the hard rule

When the focused field is a secure / password-type input, Juno enters the **Blocked** HUD state. While blocked:

- No microphone capture (the session never reaches Listening)
- No context collection (selected text, clipboard, field title all ignored)
- No transcript saved to History
- No audio retained, even if recording retention is on globally
- No correction learning
- No paste attempt, even if somehow text existed

There is no setting that disables this rule. See [Secure Fields](/docs/privacy-and-data/secure-fields).

## Never enabled

- Use audio, transcripts, corrections, or any user data to train AI models
- Run a server-side account system
- Send usage analytics or crash telemetry without explicit opt-in
- Sync data between Macs (each Mac has its own memory and history)
- Read clipboard or selected text outside an active dictation session
