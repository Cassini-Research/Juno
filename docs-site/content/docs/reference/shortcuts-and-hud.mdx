# Shortcuts and HUD

Reference for the dictation shortcut and HUD states.

## Shortcut

| Default | Press once | Press again | Cancel |
| --- | --- | --- | --- |
| **Fn / Globe** | Open the HUD; start a session | Finalize; insert or Copy Ready | Esc, mid-session |

Other shortcut options in Settings → Dictation: Right Command, Right Option, Option+Space, Control+Space. Anything other than Fn / Globe may need Input Monitoring.

## HUD states

State names come from `JunoHUDState.swift` in the shipped app.

| State | Phase | What to do if it stalls |
| --- | --- | --- |
| **Checking** | Verifying engine + surface readiness | Usually &lt;1s. Repeated stalls → [Voice Engine Not Connected](/docs/troubleshooting/voice-engine-not-connected) |
| **Checking microphone** | Waiting for the OS to deliver audio frames | [Microphone troubleshooting](/docs/troubleshooting/microphone) |
| **Waiting for speech** | Frames arriving, no speech energy yet | Speak louder, closer, reduce noise |
| **Listening** | Capturing dictation | Normal — keep speaking |
| **Refining** | Engine processing the segment | Normal; resolves in 1–2 s |
| **Partial commit** | Polished partial being placed in the field | Brief — visual confirmation a chunk landed |
| **Inserted** | Final text placed in the focused field | Done |
| **Copy Ready** | Text exists but insertion was skipped | Copy from HUD, paste manually |
| **Blocked** | Secure / password field detected | Move to a normal text field — intentional |
| **Error** | Permission, engine, or microphone failure | Read the HUD message and follow the linked guide |

## Copy Ready triggers

Six conditions, any one of which → Copy Ready instead of insertion:

- Accessibility permission missing
- Field is a secure / password input (HUD shows **Blocked**, not Copy Ready)
- Focus changed during the session
- Session was cancelled
- App rejects programmatic paste (some Electron apps, remote desktop windows)
- App's insertion method is unreliable for this field type

Full reference: [Insertion and Copy Ready](/docs/troubleshooting/insertion-and-copy-ready-output).
