# Troubleshooting Quick Reference

Symptom → first check → reference.

| Symptom | First check | Reference |
| --- | --- | --- |
| **HUD never appears** | Confirm Juno is running and the shortcut in Settings matches what you pressed | [Shortcuts and HUD](/docs/start/shortcuts-and-hud) |
| **HUD stuck on Checking microphone** | Microphone permission granted? Right input device selected in System Settings → Sound? | [Microphone](/docs/troubleshooting/microphone) |
| **HUD reaches Waiting for speech but never Listening** | Speak louder or closer to the mic; check background noise; on laptops, the built-in mic catches room reflections | [Microphone](/docs/troubleshooting/microphone) |
| **HUD stuck on Refining for &gt;3 s** | Engine slow; open Settings → Models, click Repair on the affected model | [Voice Engine Not Connected](/docs/troubleshooting/voice-engine-not-connected) |
| **HUD shows Blocked** | Secure / password field was detected; intentional — move to a normal text field | [Secure Fields](/docs/privacy-and-data/secure-fields) |
| **Text shows as Copy Ready instead of inserting** | Accessibility granted? App accepts programmatic paste? Did focus shift mid-session? | [Insertion and Copy Ready](/docs/troubleshooting/insertion-and-copy-ready-output) |
| **Wrong words / hallucinated text** | Speak closer to the microphone; add proper nouns to Dictionary; check whether the active style is a transformation style | [Transcription Accuracy](/docs/troubleshooting/transcription-accuracy) |
| **Home says voice engine is not ready** | Settings → Models → Install or Repair on each failed row | [Voice Engine Not Connected](/docs/troubleshooting/voice-engine-not-connected) |
| **Permission shows granted but Juno disagrees** | Quit Juno from menu bar, reopen; toggle the permission off/on in System Settings | [Permissions Reset](/docs/troubleshooting/permissions-reset) |
| **macOS update broke everything** | Permissions revoked silently — re-grant Microphone + Accessibility | [Permissions Reset](/docs/troubleshooting/permissions-reset) |
| **History is empty** | Complete one successful dictation; verify history is not off globally or per-app | [History and Recordings](/docs/reference/history-and-recordings) |
| **History entry has no Replay** | Recording expired (default 30 d) or recordings retention is off | [Recordings](/docs/use-juno/recordings) |
| **Reprocess button is greyed out** | The linked audio is gone; only the transcript remains | [Recordings](/docs/use-juno/recordings) |
| **"Hey Juno, ..." does not create anything** | Confirm Voice Actions is enabled and the specific integration has Automation permission | [Voice Actions](/docs/use-juno/actions) |
| **Selected-text rewrite produces no replacement** | Selected text context must be on; destination must not be a secure field | [Styles](/docs/use-juno/styles) |
| **One specific app always misbehaves** | Per-app writing settings, or app rejects programmatic paste — see app-specific notes | [App Integrations](/docs/use-juno/app-integrations) |
| **Want to wipe everything and restart** | See full uninstall sequence | [Uninstall](/docs/troubleshooting/uninstall) |

## Fast clean test

Before changing settings, run this five-step isolation:

1. Quit and reopen Juno from the menu bar
2. Open Apple Notes
3. Click into a blank note
4. Press Fn / Globe, say *"This is a Juno test."*, press Fn / Globe again
5. If text inserts cleanly → the issue is specific to the original app. If it fails → follow the symptom row above.
