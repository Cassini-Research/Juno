# Actions Reference

Reference for Voice Actions.

## Compound utterances

Juno's action grammar parses **every action verb in the sentence after "Hey Juno"** and creates one item per verb. Between verbs, separators (`and`, `,`, `also`, `then`, `plus`, `next`) split bodies cleanly.

| Say | Items created |
| --- | --- |
| *"Hey Juno, take a note about the Q3 plan and remind me to send it tomorrow at 9am."* | 1 note + 1 reminder |
| *"Hey Juno, remind me to call Sam at 3 and email Lily tomorrow."* | 2 reminders |
| *"Hey Juno, set an alarm for 7am, remind me to send the deck by 9, and note: prep the board meeting."* | 1 alarm + 1 reminder + 1 note |

## Action prefix

| Prefix | Where it goes |
| --- | --- |
| **"Hey Juno, …"** | Triggers Action routing during an active dictation session |
| **"Juno, …"** | Shorter form; same behavior |

Press the Juno shortcut to start a session, then say the prefix. The prefix matters only at the start of a transcript — mid-sentence mentions stay as plain dictation.

## Verbs

**Reminders:** `remind me`, `reminder`, `set a reminder`, `remember to`, `remember that`

**Notes:** `take a note`, `make a note`, `take note`, `note this`, `note that`, `save this note`, `save a note`, `save this`, `jot this down`, `jot down`, `write this down`, `write that down`

**Alarms (Calendar-backed):** `set an alarm`, `alarm`, `alarm at`, `wake me`, `wake me up`, `set a timer for`, `set a timer`, `ping me at`, `ping me`

## Relative-time defaults

| Say | Resolves to |
| --- | --- |
| `later` | +2 hours (snapped to next 5-min boundary) |
| `soon` | +30 minutes |
| `tonight` | 8:00 PM today (or tomorrow if past 8 PM) |
| `morning` | 8:00 AM today or tomorrow |
| `afternoon` | 2:00 PM today or tomorrow |
| `evening` | 7:00 PM today or tomorrow |
| `weekend` | Next Saturday at 9:00 AM |
| `next week` | Next Monday at 9:00 AM |

Concrete times (`at 4:30`, `in 25 minutes`, `tomorrow at 9`, `on the 15th`, `next Tuesday at 2`) parse directly.

## Recurrence

| Pattern | Example |
| --- | --- |
| Weekly | *"remind me every Tuesday at 4 to send the weekly update"* |
| Weekday-only | *"remind me every weekday at 9 to start the standup"* |
| Daily | *"remind me every morning to take vitamins"* |
| Monthly | *"remind me on the first of every month to file expenses"* |

The recurrence becomes a real `EKRecurrenceRule` in Apple Reminders.

## Follow-up corrections

After an action saves, you have a brief confirmation window to adjust without starting a new session:

| Say | Effect |
| --- | --- |
| *"Yes"* / *"Yep"* / *"Looks good"* | Confirms |
| *"Make it 4pm instead"* | Updates the time |
| *"Cancel that"* / *"Never mind"* | Removes the just-created action |
| *"Add tomorrow morning"* | Adds a missing time |

## Action targets

| Action | Lands in |
| --- | --- |
| Reminder | Apple Reminders (default list, or a named list) |
| Note | Apple Notes, folder called **Juno** |
| Alarm | Apple Calendar (one-shot event with alert) |

## Permissions

| Integration | macOS permission | Notes |
| --- | --- | --- |
| Reminders | Reminders Automation | Granted at first use |
| Notes | Notes Automation | Granted at first use; may open Notes briefly |
| Alarms | Calendar Automation | Granted at first use |

Each is independent. Enable any subset; the others remain unavailable but dictation keeps working.

## Settings on the Actions page

| Control | Effect |
| --- | --- |
| Voice Actions master toggle | Turns the system on/off |
| Per-integration status | Allowed / Set up / Restricted / Not installed |
| Add a footer to saved notes | Appends a short Juno attribution to each saved note |
| Refresh | Re-checks macOS permission state without restarting |

## Voice Commands (separate)

Voice Commands edit text during dictation (`scratch that`, `make that shorter`, `turn that into bullets`). They use no action prefix and need no permissions. Full set: [Voice Commands](/docs/use-juno/voice-commands).
