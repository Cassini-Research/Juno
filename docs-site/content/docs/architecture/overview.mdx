# Architecture Overview

Juno is a macOS app connected to a local voice engine. Both run on this Mac; there is no server component.

## Repo layout

```
harpy-v2-oai/
├── shells/macos/Sources/JunoShell/   ← Swift macOS app (UI, HUD, insertion, history)
├── shells/macos/Sources/JunoTextMonitor/  ← AX helper for selected-text observation
├── juno_v2/                          ← Python voice engine
│   ├── asr/                          ← Speech recognition
│   ├── audio/                        ← Audio capture and preprocessing
│   ├── vad/                          ← Voice activity detection
│   ├── modes/                        ← Writing styles (verbatim, casual_chat, formal_email, …)
│   ├── transforms/                   ← Writing engine that reshapes text
│   ├── actions/                      ← Hey Juno grammar and action routing
│   ├── memory/                       ← Local dictionary, snippets, corrections
│   ├── personalization/              ← Correction learning
│   ├── insertion/                    ← Paste/keystroke insertion path
│   ├── workbench/                    ← Local storage (history, recordings, logs)
│   └── engine/                       ← Engine entry, model loading, IPC server
└── shells/macos/Tests/JunoShellTests/  ← Swift test suite
```

## What goes between shell and engine

The shell talks to the engine over a local Unix socket. The protocol is documented in `juno_v2/engine/bridge.py` and consumed by `shells/macos/Sources/JunoShell/JunoBridge.swift`. Messages are JSON over length-prefixed framing — purely on-device, no network.

Engine responses include: partials (live transcription as you speak), finals (polished result), HUD state hints, and action results (Reminders / Notes / Calendar). The shell maps these to HUD state transitions and insertion decisions.

## Failure modes

**Engine unreachable.** If the engine crashes or has not finished warming, the shell shows the failure on Home with a Repair action rather than failing silently. The shell never enters Listening if the engine is not reachable. See [Failure and Recovery Model](/docs/architecture/failure-and-recovery-model).

**Insertion target untrustworthy.** If Accessibility is missing, the focused field is a secure input, or focus shifted mid-session, the shell holds the final result in the HUD as Copy Ready rather than pasting.
