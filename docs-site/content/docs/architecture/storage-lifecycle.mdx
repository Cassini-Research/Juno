# Storage Lifecycle

Juno stores app data in local macOS support folders.

## On-disk paths

| Path | What is there |
| --- | --- |
| `~/Library/Application Support/com.juno.shell/Workbench/history.sqlite` | The transcript database |
| `~/Library/Application Support/com.juno.shell/Workbench/recordings/` | Retained audio files (m4a/wav, one per session) |
| `~/Library/Application Support/com.juno.shell/models/` | Downloaded local model files (speech + writing) |
| `~/Library/Application Support/com.juno.shell/Memory/` | Dictionary, snippets, replacements, style entries |
| `~/Library/Logs/Juno/` | Diagnostic logs — bundled by Settings → Advanced → Logs → Generate support bundle… |
| `~/Library/Preferences/com.juno.shell.plist` | Settings preferences |

Note the logs path is under `~/Library/Logs/Juno/`, not under the Application Support directory — that follows the macOS convention for per-app log directories.

## Retention

| Data | Default | Settings location |
| --- | --- | --- |
| **Transcript history** | 90 days | Settings → Storage → Keep history for |
| **Recordings** | 30 days | Settings → General → Keep recordings for |
| **Models** | Until you uninstall or repair | Settings → Models |
| **Memory** (Dictionary & snippets) | Until you delete the entry | Use the Dictionary & Memory page directly |
| **Logs** | Rolling — old logs are pruned automatically | Automatic; no setting |

Retention runs as a daily cleanup pass. You can also trigger it manually with Settings → Storage → **Clean up now**.

## Deletion controls

| Action | Where | What happens |
| --- | --- | --- |
| Delete a single history entry | History page → Delete | Removes the transcript and the linked recording (if one exists) |
| Clear history | Settings → Storage → Clear history | Wipes every transcript entry and every linked recording |
| Delete recordings | Settings → Storage → Delete recordings | Wipes all audio files; transcripts stay |
| Delete a Dictionary entry | Dictionary & Memory page | Removes that entry; future dictations no longer apply it |
| Uninstall (full wipe) | See [Uninstall](/docs/troubleshooting/uninstall) | Removes Juno + all data + permissions |

History and recordings are independent. You can keep transcripts forever and audio for a day, or disable recordings entirely while keeping a 90-day transcript log.

## What happens when a recording's history entry is deleted

Deleting a history entry also deletes the linked audio file. The reverse is not true: deleting recordings (Settings → Storage → Delete recordings) leaves the transcripts intact. The audio becomes unavailable for replay or reprocessing.

## Models — when they get re-downloaded

Models are fetched on first launch and stay on disk indefinitely. They are re-downloaded when:

- You explicitly click **Repair** on a model row in Settings → Models
- A model is missing from the expected path (manually deleted, corrupted)
- A new Juno release bumps the model version

Models are large (hundreds of MB to a few GB depending on the model). Settings → Storage shows the current disk usage.

## What is not stored

- Anything from secure-field sessions — those are blocked at capture time, so there is nothing to store
- Recordings when retention is set to **Never** — audio is discarded at the end of the session
- History entries when history is off for an app — those sessions do not get a row in the database

See [History and Recording Retention](/docs/privacy-and-data/history-and-recording-retention) for the user-facing settings and [Delete, Export, and Cleanup](/docs/privacy-and-data/delete-export-and-cleanup) for the full deletion guide.
