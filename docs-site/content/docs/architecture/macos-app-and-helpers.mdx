# Mac App and Helpers

The Mac app is a SwiftUI menu-bar application. It owns the user interface, shortcut handler, and insertion path.

## Processes

| Process | Role | Source |
| --- | --- | --- |
| **JunoShell** | The main app — windows, menu bar, HUD, shortcut, Settings, History, insertion | `shells/macos/Sources/JunoShell/` |
| **JunoTextMonitor** | An Accessibility helper that observes selected text in the focused app | `shells/macos/Sources/JunoTextMonitor/main.swift` |
| **Voice engine** | The Python engine, launched by the shell | `juno_v2/engine/` (see [Local Voice Engine](/docs/architecture/local-voice-engine)) |

## macOS capabilities Juno asks for

| Capability | Why | Lives in code at |
| --- | --- | --- |
| Microphone | Audio capture during a session | `JunoAudioCapture.swift` |
| Accessibility | Read the focused field; insert text safely | `JunoCapability.swift`, `JunoSafeInsertion.swift` |
| Speech Recognition (optional) | Apple's on-device live captions in the HUD | `JunoLiveCaptions.swift` |
| Apple Events (Reminders / Notes / Calendar) | The three Voice Actions integrations | `JunoActionCatalog.swift` |
| Input Monitoring (sometimes) | Custom shortcut combinations other than Fn / Globe | `HotkeyBridge.swift` |

## Key Swift modules

| Module | What it owns |
| --- | --- |
| `JunoOnboarding.swift` | The six-step first-launch flow |
| `JunoHUDState.swift`, `HUDStateMachine.swift` | The HUD state machine — every state shown in the dictation HUD |
| `HotkeyBridge.swift` | Shortcut capture, including Fn / Globe |
| `JunoSecureFieldPolicy.swift` | Detection of secure / password fields and the hard block |
| `JunoSafeInsertion.swift` | The paste-or-Copy-Ready decision |
| `JunoBridge.swift` | The local-socket protocol used to talk to the Python engine |
| `JunoHistoryStore.swift` | Local history database (transcripts + linked recordings) |
| `JunoSettingsView.swift` | The Settings window (General → Updates & app) |
| `JunoMainChrome.swift` | Sidebar navigation labels (Home / History / Actions / Voice Commands / Styles / Dictionary & Memory / Per-app writing / Privacy / Settings) |

## What the helper does

JunoTextMonitor is a tiny, dedicated process that holds the AX subscription for selected-text changes in the focused app. Isolating AX subscriptions in a helper process keeps the main shell unaffected by AX-side errors and lets the shell drop its own subscription when not actively dictating.

## Capabilities the shell does not request

- Audio transcription happens in the engine, not the shell.
- No remote server connection. Models download once; nothing else leaves this Mac.
- No Full Disk Access, Files & Folders, Camera, or Reminders read access. Only the capabilities listed in the table above.

See [Permissions](/docs/start/permissions) for the user-facing permission flow.
