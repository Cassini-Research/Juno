# Privacy Data Flow

Five flows are independently controlled. None leaves this Mac.

## The five flows

| Flow | When it is on | When it is off | Hard gate |
| --- | --- | --- | --- |
| **Audio capture** | During an active dictation session only | When no session is active | Mic permission missing → no capture, never silent listening |
| **Context** (selected text, current field, app/window title) | Smart Context on globally + not overridden per-app off + not in a secure field | Smart Context off globally OR per-app override OR secure field | Secure field forces it off |
| **Clipboard context** | Recent-clipboard toggle on (off by default) + not in a secure field | Toggle off OR secure field | Secure field forces it off |
| **History** | History on globally + not overridden per-app off + not in a secure field | Per retention; per-app override; secure field | Secure field forces it off |
| **Recordings** | Recording retention on globally + not overridden per-app off + not in a secure field | Per retention; per-app override; secure field | Secure field forces it off |
| **Correction learning** | Learning on globally + not overridden per-app off + not in a secure field | Off any of those ways | Secure field forces it off |

## Secure field detection

The shell asks the Accessibility API whether the focused element is a secure text field. If yes, `JunoSecureFieldPolicy` returns `.blocked` and the HUD enters `Blocked` state. While blocked:

- **No capture.** Microphone does not open. The session never enters Listening.
- **No context.** No selected text, no clipboard, no field title — even if the toggles are on.
- **No history.** The session is not recorded in the transcript log.
- **No audio retention.** No file is written even if recording retention is on.
- **No learning.** Nothing the user does in the session feeds back into personalization.
- **No paste.** Even if somehow text existed, it cannot be inserted into the field.

This applies before any user setting. There is no "force on for secure fields" toggle. See `JunoSecureFieldPolicy.swift` for the policy and `SecureFieldPolicyTests.swift` for the test cases.

## Per-app overrides

Per-app writing settings can make any flow stricter than global, but never looser. The override matrix:

| Global setting | Per-app override | Effective behavior |
| --- | --- | --- |
| History on | "off" for app X | Off for X, on everywhere else |
| History off | "on" for app X | Still off (override cannot unlock) |
| Context on | "off" for app X | Off for X, on everywhere else |
| Context off globally | "on" for app X | Still off (override cannot unlock) |
| Secure field detected | Anything | Forced off regardless |

## What never leaves this Mac

- Audio frames (never sent anywhere, ever)
- Transcripts (live in `~/Library/Application Support/com.juno.shell/`)
- Retained recordings (same path)
- Dictionary & Memory entries
- Settings
- Corrections used for personalization

The only network activity in normal operation is model file downloads from a public model repository, performed once when a model is missing or being updated. Those are read-only file fetches — nothing about you or your usage is sent in the request.

## Training data

No audio, transcript, correction, or memory entry is sent off-device or used to train any model. Shipped models are pre-trained checkpoints used read-only.

See [Privacy and Data Overview](/docs/privacy-and-data/overview) for the user-facing version of this.
